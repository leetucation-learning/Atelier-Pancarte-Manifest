# Atelierul de creație · Pancarte Manifest

Curs e-learning din programul **Imagine Sunet ’89 · Manifest**. Atelier de creație: de la memorie la mesaj, pancarte mari și manifeste-colaj pentru spațiul public. 12 ecrane, voce și subtitrare în română.

E-learning realizat de **LEETUCATION SRL** · Finanțat de Municipiul Timișoara prin Centrul de Proiecte.

*An HTML e-learning course (SCORM 2004 3rd Edition) in Romanian. Works from an LMS, from GitHub Pages and offline from a PC; phone-friendly.*

## Cum îl deschizi

- **Online:** pagina GitHub Pages a acestui depozit (Settings > Pages arată adresa).
- **Pe calculator, fără internet:** Code > Download ZIP, dezarhivezi, deschizi `index.html`.
- **Într-un LMS (Moodle, Oracle Learning, SCORM Cloud):** încarci arhiva `Atelier_PancarteManifest_RO_v1.1_SCORM2004.zip` ca SCORM 2004 3rd Edition.

Online sau de pe calculator, progresul rămâne doar în browserul elevului. Pentru urmărire, cursul se încarcă în LMS.

## Publicare pe GitHub Pages

1. Depozit public, cu `index.html` în rădăcină.
2. Add file > Upload files: tot conținutul arhivei, în două ture (pagina primește cel mult 100 de fișiere o dată): întâi tot în afară de folderul `audio`, apoi folderul `audio`. Commit changes.
3. Settings > Pages > Source: Deploy from a branch > `main`, `/ (root)`.
4. După bifa verde din Actions, cursul e la `https://<utilizator>.github.io/<depozit>/`.
